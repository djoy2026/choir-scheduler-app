Stack
- Flutter
- Dart
- Supabase

Requirements
- Never remove existing features without approval.
- Preserve current authentication flow.
- Preserve ministry separation logic.
- Prevent double-booking.
- Use responsive layouts.

- Keep changes small and reviewable.
