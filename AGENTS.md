# Choir Scheduler App

Stack
- Flutter
- Dart
- Supabase

Requirements
- Never remove existing features without approval.
- Preserve current authentication flow.
- Preserve ministry separation logic.
- Prevent double-booking.
- Use responsive layouts.
- Create migrations for database changes.
- Keep changes small and reviewable.
- Never modify Supabase production data.
- Generate SQL migration scripts but do not execute them.

- User login
- Claim/unclaim slots
- Admin assignment
- Monthly schedule page
- Children's Ministry scheduling
- Conflict prevention between ministries
